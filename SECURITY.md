# Security policy

## Reporting a vulnerability

Please report security issues privately to the maintainer at chetanbiranje@proton.me. Include the affected version or commit, a concise description, impact and safe reproduction steps using an authorized environment. Do not include credentials, personal data or third-party confidential information.

Please avoid public disclosure of unresolved vulnerabilities. No response time, bounty or production support is guaranteed.

## Safe use

Use this repository only in authorized environments. Review dependencies and configuration before deployment. Research examples are not a substitute for an independent security assessment.
