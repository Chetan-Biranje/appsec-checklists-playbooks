# Contributing

Corrections and additions are welcome.

1. Open an issue first if the change is large, so we can agree on scope.
2. Keep checklist items short, testable and specific. One check per line.
3. Name the source (OWASP, CIS, vendor documentation) when an item comes from one.
4. Do not include real credentials, customer data or details of vulnerabilities in systems you do not own.

Pull requests are reviewed on a best-effort basis.
